# Rust dedicated server: scripts, configuration and menu plugin

Настройка modded сервера Rust на Windows: Carbon вместо Oxide, скрипты запуска,
конфиги всех плагинов и собственный плагин меню.

## Что здесь лежит, а что нет

В репозитории нет игровых файлов и бинарников плагинов. Их нельзя хранить в git: пять
файлов игры крупнее 100 МБ, а лимит GitHub на файл ровно 100 МБ. К тому же это
собственность Facepunch, и чужие плагины распространять нельзя. Всё это ставится одной
командой SteamCMD, поэтому в репозитории оно не нужно.

| Папка | Что внутри |
|---|---|
| `configs/carbon/` | Конфиги всех плагинов Carbon, очищенные от вебхука Discord |
| `configs/kits/` | Набор новичка для плагина Kits |
| `configs/permissions/` | Права по группам и шаблон владельца сервера |
| `docs/PLUGINS.md | Список плагинов с версиями и ссылками |
| `plugins-source/` | Исходник плагина меню |
| `run.example.bat` | Шаблон запуска сервера |
| `validate.bat` | Проверка файлов игры после обновления |

## Установка с нуля

### 1. SteamCMD и сервер

Скачать SteamCMD и положить в папку `steamcmd` рядом с этим репозиторием.

```bat
cd steamcmd
steamcmd.exe +force_install_dir ..\server +login anonymous +app_update 258550 validate +quit
```

Папка `server` весит около 6 ГБ и скачивается целиком при первом запуске.

### 2. Carbon

Установить Carbon в папку `server` и запустить его установщик, чтобы появились
`carbon\plugins`, `carbon\configs` и `carbon\managed`.

### 3. Конфиги плагинов

Скопировать `configs\carbon\*.json` в `server\carbon\configs\` с заменой файлов,
копию `configs\kits\kits_data.json` в `server\carbon\data\Kits\`.

Перед копированием подставить свой вебхук Discord вместо
`REPLACE_WITH_YOUR_WEBHOOK_URL` в `AdminLogger.json` и `AdminRadar.json`. Это
единственные два файла, где есть секрет.

### 4. Плагины

Скачать плагины из списка в `docs/PLUGINS.md` в `server\carbon\plugins\`.
`RLXMenu.cs` взять из `plugins-source`.

### 5. Запуск

Скопировать `run.example.bat` в `run.bat`, задать своё имя сервера, пароль RCON и
свой SteamID в шаблоне владельца. Запускать скриптом, а не двойным щелчком: он
сначала обновляет игру, потом поднимает сервер и не даёт запустить второй экземпляр.

```bat
run.bat
```

## Порты

| Порт | Протокол | Назначение |
|---|---|---|
| 28015 | UDP | Игра |
| 28017 | UDP | Steam |
| 28083 | TCP | Rust+ |
| 28016 | TCP | RCON |

Все четыре нужно пробросить на роутере и открыть в брандмауэре Windows. Без проброса
UDP 28015 сервер не появится в общем списке игр, а Rust+ не подключится.

Открывать RCON наружу небезопасно: он даёт полный контроль над сервером тому, кто знает
пароль. Если RCON нужен только для удалённого управления, безопаснее оставить порт
закрытым и заходить через SSH или VPN.

## Владелец и права

В `server\server\moddedrust\cfg\users.cfg` добавить свой SteamID64 через `ownerid`.
Владелец может всё и не может быть забанен или кикнут, включая другими админами.

Разбивка прав по группам в `configs\permissions\groups.json`. Выдать право из консоли:

```
c.grant group admin nteleportation.admin
c.grant group default backpacks.use
```

Перезагрузить плагин после правок: `c.reload Kits`.

## Стартовый набор и дропы

Стартовый набор `starter` лежит в `configs\kits\kits_data.json` и выдаётся вручную
командой `/kit`. Автовыдача при респауне отключена намеренно: она срабатывала бы при
каждой смерти и давала бы бесконечные камни и палки.

Ежедневные дропы по расписанию настроены на FancyDrop, время 18:00 по серверу.
Случайные дропы в промежутках 30-60 минут отключены, чтобы лут не сыпался постоянно.

## Мир и карта

Карта процедурная, размер 3500, сид 12345, до 50 игроков. Чтобы сгенерировать новую
карту, удалите папку `server\server\moddedrust` и перезапустите сервер.

## Уведомления в Discord

AdminLogger и AdminRadar умеют отправлять сообщения в Discord через вебхук. В
`configs/carbon/AdminLogger.json` и `AdminRadar.json` впишите адрес вебхука и включите
отправку. Вебхук позволяет писать в канал, поэтому не публикуйте его адрес: замените на
заглушку перед тем, как делиться конфигами.

## Особенность кириллицы в плагинах

Компилятор Carbon читает исходники в системной кодировке, и кириллица в файлах `.cs` и
`.json` портится: это не лечится ни UTF-8, ни UTF-8 с BOM, ни CP1251. Русские строки
нужно писать escape-последовательностями вида `Добро пожаловать`. Исходник остаётся
ASCII, а строка получается корректной. В плагине меню сделано именно так.

## Безопасность

`run.bat` с паролем RCON не коммитится и остаётся только на машине. Публичная история
репозитория навсегда: если секрет всё же попал в коммит, удалить его из истории
недостаточно, его нужно сменить.
