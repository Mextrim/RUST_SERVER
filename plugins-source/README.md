# RLXMenu

Собственный плагин сервера: меню при входе и экран с правилами.

## Что делает

- Через 12 секунд после входа показывает меню с кнопками: набор новичка, телепорт домой, игроки онлайн, правила, закрыть.
- Показывает меню только когда игрок жив. Если игрок умер при входе, плагин ждёт до 30 секунд и открывает меню после возрождения.
- Приветствие в чат при входе.
- `/menu` открывает и закрывает меню, `/rules` открывает правила.
- Экраны не накладываются: открытие одного закрывает другой.

## Установка

Скопировать `RLXMenu.cs` в папку плагинов Carbon, то есть `server\carbon\plugins\`.
Carbon подхватит файл сам и пересоберёт плагин, перезапускать сервер не нужно.

## Настройки

Файл `server\carbon\configs\RLXMenu.json`: цвета, задержка показа, показывать ли меню при входе, текст приветствия.

Русские надписи заданы в коде через escape-последовательности вида `\u0414`. Это сделано намеренно: компилятор плагинов Carbon читает исходники в системной кодировке и портит кириллицу в файлах. Escape-последовательности оставляют исходник чистым ASCII, а строки остаются корректными.

## Важно про интерфейс

Плагин собирает CUI JSON вручную, а не через классы `CuiPanel` и `CuiButton` из Carbon. У Carbon своя схема сериализации: кнопка получается без блока `button`, клиент её рисует, но не обрабатывает нажатие. Поэтому используется стандартный формат Oxide: `"type":"Button"` с вложенным объектом `"button"`.

## Команды кнопок

Кнопки отправляют клиентские команды: `kit` (Kits), `home` (NTeleportation), `who`, `rules`, `menu`. Если Kits или NTeleportation не установлены, соответствующие кнопки не сработают.
